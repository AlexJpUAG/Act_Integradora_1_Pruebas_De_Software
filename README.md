# Conversor de Unidades

Proyecto desarrollado en Python para realizar conversiones de:

- Celsius a Fahrenheit
- Fahrenheit a Celsius
- Kilómetros a Millas
- Millas a Kilómetros
- Pesos Mexicanos a Dólares
- Dólares a Pesos Mexicanos

La conversión de moneda utiliza una tasa fija de:

1 USD = 18.50 MXN

## Requisitos

Python 3.x

## Instalación

Instalar las dependencias con:
